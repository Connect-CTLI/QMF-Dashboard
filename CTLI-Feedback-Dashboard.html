Connect live responses

Feedback comes from two Google Forms — the main CTLI Professional Learning Feedback form, and a separate Facilitator Feedback form. Publish each form's response sheet as CSV (File → Share → Publish to web → responses tab → CSV → Publish) and paste both links below. The dashboard merges them, so loading one never overwrites the other.
Links are remembered — once loaded, this browser reloads both sheets automatically next time the dashboard opens.

Link the register (live)

The Course & Session Register has three tabs. Publish each one as CSV (File → Share → Publish to web → pick the tab → CSV) and paste its link below — same as the response sheet.
Prefer a one-off upload instead of a live link? Use Import register (.xlsx) on the Catalogue tab — same result, no link required.

How the form maps

Three things let the dashboard read each response:
A

Session key (same on both forms)

Both forms' session question uses the same plain session key:
20 Feb · SACE Ethics Seminar [2701]
Copy the list from Catalogue → Copy session options and paste it into each form's session question.

B

Who facilitated (facilitator form only)

The facilitator form has a separate "Select your facilitator" checkbox question — respondents tick who ran the session, e.g. F03 A. Petersen. Ticking more than one attributes the same ratings to each. If nobody ticks a name, the dashboard falls back to whoever the register has assigned to that session. Copy the checkbox options from Catalogue → Copy facilitator roster.

C

Rubric matching

Each Likert question is matched by its actual wording, not a code prefix — e.g. a column containing "pitched at the right level of depth" is read as C2, and "demonstrated good knowledge of the subject" is read as D1.1. This means the sheet can be pasted in exactly as Google Forms exports it.

Numbers or text? Both are read. Numbered answers ("4" or "4 - Agree") use the leading digit. Plain-text agreement answers ("Strongly agree", "Agree", "Disagree", "Strongly disagree") are also read directly. Other plain-text scales need their exact wording confirmed before they're added.
