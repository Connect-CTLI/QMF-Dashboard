Connect live responses

The dashboard reads feedback from your form's response sheet, or from two, if facilitation feedback sits in its own form. One-time setup:
1

Link each form to a Sheet

CTLI Professional Learning Feedback → Responses → link to Sheets. If facilitation has its own form, link that one too, either to its own sheet or as a second tab in the same one.

2

Publish each as CSV

File → Share → Publish to web → responses tab → CSV → Publish. Do this once per form.

3

Paste the link(s)

One form only? Fill in the first field and leave the second blank. Two forms? Paste both. The dashboard fetches and merges them on load.

Links are remembered on this device and reloaded automatically next time.

How the form maps

Two things let the dashboard read each response, in either form:
A

Session key

Q1 = "Select the session you attended" (or the equivalent PLO question). Each option ends in the session ID in brackets:
20 Feb 2026 · Leadership Conference [2701]
The dashboard reads 2701 from that key. No facilitator ID needs to be embedded, the register (Courses/Sessions/Facilitators, loaded further down this page) tells the dashboard who ran that session. A co-facilitated session with no explicit facilitator selector credits every assigned facilitator equally. Copy the whole session list from the Catalogue tab when building the form's dropdown.

B

Question wording, not codes

Questions don't need a rubric code prefix. The dashboard matches each question by its wording, for example a question containing "Ease of platform use" maps automatically to the Digital & Online section. Answers can be numbered (3 - Good) or plain text (Strongly agree); both convert to a 1–4 score. "Not Applicable" and blank answers are excluded rather than counted as zero.

One form or two? Either works. Keep everything in one form and paste one link above, or split facilitation into its own form and paste both links. The dashboard pools rows from both sheets by session, so a course-feedback row and a facilitation row for the same session simply combine into one picture rather than needing to line up as a single submission. If you change a question's wording, keep it close to what's on file, since the matcher looks for the same key phrases each time.
